# 子代理开发

逐任务分派新子代理，每任务后执行二阶段审查。

## 流程

```
读取计划 → 提取所有任务 → 创建 TodoWrite
  ├─ 每任务循环:
  │   1. 分派实现子代理（含完整任务描述 + 上下文）
  │   2. 子代理实现、测试、提交、自审
  │   3. 分派规格审查子代理（确认代码匹配设计）
  │   4. 分派代码审查子代理（确认代码质量）
  │   5. 标记完成 → 下一任务
  └─ 全部完成后 → 分派最终审查 → 调用「完成分支」技能
```

## 核心规则

- 每任务一个**新**子代理（避免上下文污染）
- 实现子代理必须先问清楚再动手
- 规格审查在代码审查**之前**（先确认做对了，再确认做得好）
- 发现问题 → 修复 → 重新审查，循环直到通过
- **不问用户**是否继续 — 连续执行所有任务
- 只有阻塞性错误、无法消歧、或全部完成时才停下来

## 模型选择

- 机械实现任务（接口清晰、1-2 文件）→ 快速便宜模型
- 集成任务（跨文件协调）→ 标准模型
- 审查任务 → 最强模型

## 子代理状态处理

| 状态 | 处理 |
|------|------|
| DONE | 进入审查 |
| DONE_WITH_CONCERNS | 先评估疑虑再审查 |
| NEEDS_CONTEXT | 补充上下文后重新分派 |
| BLOCKED | 升级模型或减化任务；不改动就重试是浪费 |
